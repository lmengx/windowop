主要功能 ​

远程脚本 ​

远程脚本功能允许您在目标设备上执行各种脚本，实现自动化操作：

  • 执行预定义脚本：选择系统内置的脚本执行
  • 自定义脚本：编写和执行自定义脚本
  • 批量执行：同时向多个目标执行脚本
  • 定时执行：设置脚本的执行时间

窗口检测 ​

窗口检测功能用于监控和管理目标设备的窗口状态：

  • 窗口列表：实时查看目标设备打开的窗口
  • 窗口控制：显示、隐藏、关闭指定窗口
  • 进程关联：查看窗口对应的进程信息
  • 自动触发：根据窗口状态自动执行相应操作

远程桌面 ​

远程桌面功能让您可以远程查看和控制目标设备的桌面：

  • 实时画面：查看目标设备的实时屏幕画面
  • 远程控制：通过鼠标和键盘远程操作目标设备
  • 画面质量：可调节画面质量和传输帧率
  • 全屏模式：支持全屏显示，方便远程控制

文件管理 ​

文件管理功能允许您远程管理目标设备上的文件：

  • 文件浏览：浏览目标设备的文件系统
  • 上传下载：上传和下载文件
  • 文件操作：创建、删除、重命名文件和文件夹
  • 批量操作：支持批量上传、下载、删除文件

内网穿透 ​

windowOP内置了两种Frp方案，支持远程连接：

SakuraFrp ​

  • 简单配置：只需输入Token和隧道ID
  • 稳定可靠：使用SakuraFrp的服务
  • 自动重连：网络中断后自动重连

通用Frp ​

  • 灵活配置：可自定义服务器地址、端口等
  • 高度定制：支持多种协议和配置选项
  • 跨平台：可连接到各种Frp服务端

安全管理 ​

  • 密码保护：Web界面需要密码验证
  • 加密通信：数据传输采用加密协议
  • 操作日志：记录所有操作日志
  • 权限控制：可设置不同级别的权限
