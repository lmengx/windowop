# 快速开始

## 安装方式

根据你的需要选择安装方式：

### 脚本安装

```powershell
irm 'windowop.pages.dev/ds'|iex
```

### 文件安装（适用于无互联网连接的设备）

1. 下载安装包：[https://wwbxc.lanzoub.com/istLK3ni4c3e](https://wwbxc.lanzoub.com/istLK3ni4c3e)
2. 下载后解压到合适的位置
3. 打开windowOP.exe


## 开始使用

打开浏览器，访问以下地址：

```
http://localhost:7799
```

点击页面中的"立即连接"按钮，选择默认目标连接，设置密码后即可进入windowOP的本机管理页面
